| Capa         | Responsabilidad                                       |
| ------------ | ----------------------------------------------------- |
| Routes       | Define los endpoints de la API.                       |
| Controllers  | Recibe la petición HTTP y devuelve la respuesta.      |
| Services     | Implementa la lógica de negocio.                      |
| Repositories | Ejecuta las consultas SQL.                            |
| Models       | Representa las entidades y valida o transforma datos. |
| Config       | Configuración de Oracle y variables de entorno.       |
| Middlewares  | Autenticación, validación y manejo de errores.        |
| Utils        | Funciones reutilizables.                              |
